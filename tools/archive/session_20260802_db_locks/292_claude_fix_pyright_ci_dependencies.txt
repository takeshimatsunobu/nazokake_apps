【ミッション: CI環境におけるPyright型検査の依存関係エラー（reportMissingImports）の修正】
GitHub ActionsでのPyright実行時、apps/evaluator/backend/api/routers/ 配下のファイルで fastapi 等のインポートが解決できず、Exit code 1でハードフェイルする障害が発生している。原因を調査し、CIワークフローを改修せよ。

Step 1: ワークフローの監査
.github/workflows/ 配下のPyrightを実行しているYAMLファイル（pyright_check.yml 等）を解析し、uv run python tools/pyright_tool.py が実行される前に、バックエンド（apps/evaluator/backend）等の依存パッケージがCIランナー上に正しくインストールされていない構造的欠陥を特定せよ。

Step 2: ワークフローの改修
Pyrightが型検査を行うための前提条件として、対象となる依存関係（FastAPI等）がCI環境に解決されるよう、YAMLファイルに依存関係インストールステップ（該当ディレクトリでの uv sync 等）を追加せよ。

Step 3: 静的解析と厳密なコミット
実装後、YAMLの構文エラーがないことを確認せよ。
検証完了後、変更したYAMLファイルを明示的に指定してGitコミットを行え。
※絶対制約: git add . は厳禁である。必ず対象ファイルパスを個別に指定すること。
