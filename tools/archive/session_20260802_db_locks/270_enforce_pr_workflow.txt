【ミッション: PRベース運用の強制とDirect Pushの完全禁止】

システムの監査性と安全性を高めるため、Agentが main ブランチに対して直接コミットおよびプッシュを行う現在の運用を廃止し、完全なGitOps（PRベース運用）へアーキテクチャを刷新します。以下の要件（Must Fix）に基づき、オーケストレーターを修正してください。

Step 1: AgentフローにおけるDirect Pushの禁止
tools/agent_graph.py または関連するGit操作モジュールをAST解析し、git push origin main（または現在のブランチへの直接Push）を行っている箇所を特定・削除してください。

Step 2: 1タスク1ブランチとPR自動作成の実装
自己修復やコード改修タスクを開始する際、Agentは必ず以下の決定論的フローを実行するようロジックを改修してください。

タスクの意図を示す一意なブランチ（例: feature/auto-fix-<hash>）を新しく切ってチェックアウトする。

修正対象ファイルのみを個別に git add <対象ファイルパス> でステージングし、コミットする（git add . の使用は厳禁）。

新規ブランチをリモートへプッシュする。

GitHub CLI (gh pr create) またはGitHub APIを用いて、自動的にPull Requestを作成する（Draft PRとするか、レビュアーを指定する）。

Step 3: 安全性の担保とAST検証
上記の実装は必ずASTベースの安全な操作（LibCST等）で適用し、修正後のコードが pyright および既存のテスト（pytest）を通過することを確認してください。実装完了後、この変更自体を「PRベースのワークフロー」を用いてリモートへ提出してください。
