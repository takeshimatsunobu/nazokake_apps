【ミッション: エスカレーションブランチおよび一時 worktree の自動クリーンアップ機構の実装】
異常終了等で残留したGitワークツリーやエスカレーション用の一時ブランチを自律的にパージし、システムのストレージ枯渇およびGitのパフォーマンス劣化を決定論的に防ぐガベージコレクション（GC）機構を実装してください。

Step 1: クリーンアップロジックの実装 (tools/cleanup_resources.py 新設)
システムのリソースを安全に破棄するスクリプトを新設してください。

git worktree prune をサブプロセスとして実行し、ディレクトリが物理削除されてリンク切れとなったworktree情報をGitの内部管理からパージする処理。

escalation/ などのプレフィックスを持つ一時ブランチを列挙し、最終コミットから一定時間（例: 24時間）が経過している古いブランチを git branch -D で安全に削除する処理。

【絶対制約】 main, master, 現在チェックアウトされているブランチなど、コアとなるブランチを決して削除しないよう、厳格な保護リスト（Denylist）をコードレベルで設けること。

Step 2: ライフサイクル管理のスケジューラ統合
実装したクリーンアップロジックを tools/scheduler_daemon.py にインポートし、定期実行ループの中で（例えば1日に1回程度）非同期またはノンブロッキングに実行されるよう組み込んでください。
クリーンアップの実行ログ（パージされたブランチ名等）は、必ず run/audit_reports/cleanup.log 等の揮発性ディレクトリへ出力し、トリアージ可能にすること。

Step 3: 厳格なコミット
実装後、Ruff等で構文エラーがないことを確認してください。
確認完了後、新設および変更したファイル群を明示的に指定してGitコミットを行ってください。
