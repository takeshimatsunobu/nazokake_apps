【ミッション: GitHub Branch Protectionの有効化（物理的ロックイン）】

完全なGitOpsアーキテクチャを担保するため、GitHub側のプラットフォーム機能を用いて main ブランチへの直接Pushを物理的にブロック（Fail-Closed）します。Agentは、GitHub CLI (gh) または GitHub API を駆使して、以下の保護ルールを設定および検証してください。

Step 1: Branch Protection ルールの適用
gh api コマンド等を使用して、現在のリポジトリの main ブランチに対し、以下の保護ルールを適用してください。（GUIで手動設定する必要がある場合は、ユーザーにその旨を案内し、設定完了を待機してください）

[要求される保護設定]

PRの必須化 (Require a pull request before merging)

ステータスチェックの必須化 (Require status checks to pass before merging)

必須とするチェック項目: 前回のタスクで追加した pytest および Pyright type-check gate を含むCIジョブ名（例: GitHub ActionsのYAMLで定義されているJob名）を指定する。

管理者のバイパス禁止 (Enforce all configured restrictions for administrators)

Step 2: 適用状態の監査
ルール設定後、設定が正しく反映されているかをAPI経由で取得し、監査可能なファクトとして出力してください。
取得コマンド例:
gh api repos/{owner}/{repo}/branches/main/protection

Step 3: 結果報告
設定の完了後、取得した保護ルールの設定内容（JSON等の抜粋）と、ステータスチェックとして登録されたCIジョブ名の一覧をサマリーとして出力してください。
