【ミッション: Agent UXを保護したGit運用ガードレールの構築およびインデックスパージ】
モノレポ構造におけるGitツリー汚染を解消し、AIの自律稼働を阻害しない決定論的なガードレールを構築してください。

Step 1: .gitignore の厳格化
プロジェクトルートの .gitignore を確認し、以下の要素を明示的に追跡除外として定義してください。
・仮想環境ディレクトリ: .venv/, .venv_ai/, .venv_train/
・SQLite関連ファイル: *.db, *-wal, -shm
・出力物およびログ: tools/audit_reports/, _tmp/, *.log, pycache/

Step 2: Read-only な pre-commit フックの設定
.pre-commit-config.yaml をプロジェクトルートに作成し、以下の要件を満たすフックを定義してください。
・巨大ファイル検知（check-added-large-files）および基本的な構文エラー検知のみを有効化する。
・Linter（Ruff）を組み込む際は、自動修正を行わないよう args: [--no-fix] を明示的に指定する。
・ruff-format 等のテキスト整形系フックは、AIのコンテキストとファイル実態の乖離を生むため絶対に使用しない。

Step 3: ドライランを伴う安全なインデックスパージ
すでにGitインデックスに混入している不要ファイルをパージします。ルートで git rm -r --cached . を実行することは禁止します。

git rm -r --cached -n <対象ディレクトリ/ファイル> を用いてドライランを実行し、削除対象が .gitignore で定義した不要ファイルのみであることを確認する。

問題がなければドライランを外し、インデックスからパージを実行する。

Step 4: フックのインストールとコミット
pre-commit install を実行してフックをローカルにバインドした後、.gitignore と .pre-commit-config.yaml の追加、およびパージの成果を明示的に指定してGitコミットを行ってください。
コミットメッセージ例: "build: Agent UXを保護したRead-only pre-commitフックの導入とインデックスのパージ"
※エージェント作業中の運用として、フックによるブロックが自律ループの妨げとなる場合は --no-verify の使用を許可します。
