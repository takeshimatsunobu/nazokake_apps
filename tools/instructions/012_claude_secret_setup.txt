Cloud Runへのデプロイにおいて、Secret Manager上のシークレット欠落エラー（was not found）が発生しました。
以下の手順でGCP環境のプロビジョニングを行い、デプロイを再試行してください。

【要求事項】
1. ローカルの `.env` (または `apps/evaluator/.env`) から `GEMINI_API_KEY` と `ANTHROPIC_API_KEY` の値を安全に取得してください。
2. GCP Secret Manager に以下の2つのシークレットを作成し、取得した値を最新バージョン（データ）として追加してください。
   - GEMINI_API_KEY
   - ANTHROPIC_API_KEY
   (※既にシークレットが存在する場合はバージョンの追加のみを行ってください)
3. Cloud Runのサービスアカウント (`862686676938-compute@developer.gserviceaccount.com`) に対して、上記2つのシークレットへのアクセス権限 (`roles/secretmanager.secretAccessor`) を付与してください。
4. インフラのプロビジョニング完了後、再度プロジェクトルート等適切なディレクトリにて `gcloud builds submit --config cloudbuild.yaml .` を実行して本番環境へデプロイしてください。
5. デプロイの完了を待機し、ターミナルに出力された「最終的なデプロイ結果（成功・失敗の生ログ）」を抽出して報告してください。推測や自己判断による追加対応は行わないでください。
