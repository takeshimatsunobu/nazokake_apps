【ミッション: 置換エンジンのアトミック書き込み実装 (Epic 1 防弾化 - 追加課題 C)】
LLMオーケストレーターが非同期にファイルを処理する際、ファイル上書き中のプロセスクラッシュによるデータロスト（0バイト化）を防ぐため、tools/ast_modifier.py にアトミック書き込み機構を導入してください。

Step 1: アトミック書き込みヘルパーの実装

tools/ast_modifier.py を開き、以下の要件を満たすヘルパー関数 def _atomic_write_text(path: Path, text: str, encoding: str = "utf-8") -> None: を定義してください。
・tempfile.NamedTemporaryFile を使用し、対象ファイル（path）と同一のディレクトリに一時ファイルを作成する（delete=Falseを指定）。
・text を書き込んだ後、f.flush() と os.fsync(f.fileno()) を実行し、OSのバッファから物理ディスクへの完全同期を強制する。
・一時ファイルを閉じた後、os.replace(一時ファイルのパス, path) を実行して不可分（Atomic）にファイルをすげ替える。
・処理中に例外が発生した場合は、finallyブロック等で一時ファイルが残らないように確実に削除（クリーンアップ）する。

Step 2: 既存の保存処理の置き換え

apply_modification 内のファイル保存処理（ path.write_text(...) 等 ）を、Step 1で作成した _atomic_write_text の呼び出しに完全に置き換えてください。

Step 3: スモークテストとクリーンアップ

隔離環境にダミーファイル _tmp_atomic_test.py を作成し、ダミーの関数を記述してください。

その関数を置換する指示JSON（ _tmp_atomic_instr.json ）を作成し、tools/ast_modifier.py をCLIとして実行してください。

置換が成功していること、および作業ディレクトリ内に tempfile 由来の一時ファイル（tmp* など）の残骸が一切残っていないことを確認してください。

修正後の tools/ast_modifier.py に対して uv run ruff check --fix tools/ast_modifier.py を実行し、Linterを通過させてください。

テスト完了後、作成した一時テストファイル群を削除し、実行結果を報告してください。
