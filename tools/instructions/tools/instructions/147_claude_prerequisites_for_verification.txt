【ミッション: メトリクス監査開始に向けたプレレクイジット（前条件）の解決】
検証サーバーにおける6次元ベンチマーク実走（運用フェーズ）への移行を条件付きで承認する。ただし、移行の絶対的な前条件として、IaCパッケージから黙殺されていたクリティカル要件の組み込みと、コンテキスト喪失メカニズムのRCA（根本原因分析）を実施すること。

Step 1. セキュア基盤と経験再生アーキテクチャのデプロイ定義の明示
検証サーバーへの移行パッケージ（docker-compose.yml または関連する初期化スクリプト）において、既存のアトミックI/O基盤および経験再生アーキテクチャ（ai_knowledge_base.json のビルドプロセス等）が移行先環境で確実に稼働するための決定論的構成（コマンド、マウント設計等）をコードとして明示的に組み込むこと。「リポジトリをクローンしてそのまま実行する」という暗黙の前提に依存してはならない。

Step 2. コンテキスト脱落のメカニズムに関するRCA総括
タスクスコープの限定（例：「ローカルでテスト可能な範囲」への絞り込み指示）が、結果として全体アーキテクチャの重要コンテキスト（セキュア基盤等の移行要件）のサイレントな切り捨てを誘発したメカニズムについて、システム的な根本原因を総括し、レポートとして出力すること。

Step 3. 静的解析とコミット
実装後、構文エラーがないことを確認すること。検証完了後、追加・変更したIaC定義ファイルおよびRCAレポート（ドキュメント）を明示的に指定してGitコミットを行うこと。
※絶対制約: git add . は厳禁。必ず対象ファイルパスを個別に指定すること。
