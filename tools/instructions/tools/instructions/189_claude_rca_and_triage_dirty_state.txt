【ミッション: ローカル作業ツリーの未知の変更に対するRCAおよびクリーンアップ方針の立案】
現在、作業ツリーに100件以上の未知の変更（未追跡ファイルや変更済みファイル）が発生しており、SSoTの乖離（構成ドリフト）が疑われます。直ちに以下の要件（Must Fix）に従い、調査と方針立案を行ってください。

Read-Onlyの厳守（破壊的操作の絶対禁止）
git clean -fd、git reset --hard、rm -rf などの不可逆な破壊コマンドの実行を固く禁じます。現在のステップは「調査・トリアージ」のみとし、システムへの状態変更（物理削除や上書き）は一切行わないこと。

変更内容のトリアージとスナップショット確保の設計
発生している差分のリストを解析し、「必要な成果物」「一時ファイル・ゴミ」「エージェント生成物」等に分類してください。また、これらを物理削除・コミットする前に、情報の非可逆な欠損を防ぐために安全なスナップショット（git stashや別ディレクトリへのバックアップ等）を確保する手順を設計に組み込むこと。

根本原因分析（RCA）の提出
なぜ作業ツリーにこれほど大量の未知の差分が発生したのか。過去のタスク（tools/instructions/ 配下の生成物や、Nazo-Agentの自律稼働ログなど）の軌跡から根本原因を自己診断し、RCAレポートとして出力すること。

上記を完了させた上で、トリアージ結果、RCAレポート、および具体的なクリーンアップ実行手順（コマンド群）を設計案として提示してください。
