【ミッション: VRAM保護と環境ガードを強制するFastAPI起動スクリプトの開発】
FastAPIのマルチワーカー起動によるVRAM枯渇（OOM）と、仮想環境の未アクティベートによる起動エラーを防ぐため、物理的な運用規律となる起動ラッパースクリプトを作成してください。

Step 1: 起動スクリプトの作成
プロジェクトルートに run_api.ps1 を新規作成し、以下の要件を実装してください。
・【環境ガード】: スクリプト実行時、環境変数 $env:VIRTUAL_ENV が設定されているか、またはプロジェクトルートに .venv ディレクトリが存在するかをチェックしてください。どちらも満たさない場合は「仮想環境がアクティベートされていません」とエラーを出力し、即座に exit 1 で安全に終了（フェイルファスト）させてください。
・【VRAM保護】: FastAPI（uvicorn）を起動するコマンドにおいて、必ず --workers 1 をハードコードして実行してください。ユーザーが引数で --workers を渡そうとした場合は無視するかエラーとして弾いてください。
・（補足）既存のFastAPIの起動対象（例: apps.evaluator.backend.main:app）や使用ポートなどの基本設定は、現在のプロジェクトの仕様に合わせて適切に記述してください。

Step 2: 静的解析と動作確認
PowerShellスクリプト作成後、以下のスモークテストを実施して結果を報告してください。

仮想環境を無効化（デアクティベート）した状態で run_api.ps1 を実行し、環境ガードによって安全に起動がブロックされること。

仮想環境を有効化した状態で run_api.ps1 を実行し、uvicorn が --workers 1 で正常に起動すること。
