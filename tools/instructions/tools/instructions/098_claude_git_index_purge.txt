【ミッション: Gitインデックスの肥大化解消（ガベージパージ）】
リポジトリに誤って追跡（Track）されてしまった巨大な仮想環境やキャッシュファイルが原因で、Git操作やpre-commitがハングアップしています。物理ファイルは削除せず、Gitの追跡対象からのみ除外（パージ）してください。

Step 1: 巨大ディレクトリとキャッシュの追跡解除
以下のコマンド等を用いて、物理環境は壊さずにGitのインデックスからのみ削除（--cached）してください。
対象:
・ .venv, .venv_ai, .venv_train の仮想環境ディレクトリ
・ 各所にある pycache ディレクトリと *.pyc ファイル
・ *.egg-info などのパッケージビルド生成物

Step 2: データベースとログ・出力物の追跡解除
同様に以下のファイル群を追跡解除してください。
対象:
・ *.db, *.db-wal, *.db-shm などのSQLite関連ファイル
・ tools/audit_reports/ 配下のファイル
・ all_source_code.txt などの巨大なダンプファイル

Step 3: 状態の確認と報告
パージ実行後、git status を実行してインデックスから大量のファイルが削除扱い（Deleted）になっていることを確認し、サマリーを報告してください。
※重要: この時点ではまだ git commit を実行しないでください。
