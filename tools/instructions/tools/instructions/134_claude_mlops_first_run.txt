【ミッション: MLOpsパイプラインの初回手動実行と可観測性の監査】
構築が完了した防弾インフラ上で、MLOpsパイプラインが決定論的に動作するか、エンドツーエンドの疎通確認を実施します。本タスクではコードの修正やGitコミットは行わず、実行と監査のみを行ってください。

Step 1: なぞかけ用MLOpsパイプラインの実行
ターミナルで以下のコマンドを実行し、パイプラインをキックしてください。
uv run python tools/mlops_pipeline_nazo.py

Step 2: Agent用MLOpsパイプラインの実行
Step 1の処理が完走（成功、または規定通りのFail-Fast）した後、続いて以下のコマンドを実行してください。
uv run python tools/mlops_pipeline_agent.py

Step 3: 監査ログのサマリー生成
両方の実行が完了したら、以下の観点で実行結果のログ（標準出力）を解析し、ユーザーへ報告してください。
・層化抽出によるコアーセットのサンプリングが計算量O(1)レベルで正常に行われ、抽出件数が表示されたか。
・VRAM排他制御（FileLock）が各パイプラインの開始時に正しく取得され、終了時（または異常終了時）に確実に解放されたか。
・品質ゲートの判定、または正しい理由（Docker不在やベンチマーク未完等）による安全な停止（Fail-Fast / Hard-Fail）が行われたか。
・mlops_experiments.db やダッシュボード用静的JSON（metrics.json）への書き込みエラーが発生していないか。
