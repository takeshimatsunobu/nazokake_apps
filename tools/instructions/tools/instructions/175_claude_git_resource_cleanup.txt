【ミッション: Gitマージステートに基づくエスカレーションリソースの自動クリーンアップ機構実装】
Nazo-Agentの自律稼働に伴って蓄積される一時Git Worktreeおよびブランチについて、ストレージ枯渇を防ぐためのガベージコレクションを実装してください。経過時間による推測削除はシステム破壊の温床となるため禁止し、必ず「メインブランチへのマージ状態」を絶対基準としてください。

Step 1: クリーンアップスクリプトの作成
tools/cleanup_git_resources.py を新設し、以下のロジックを実装すること。
・subprocess を用いて git branch --merged main (または master) を実行し、マージ済みの escalation/* や draft/* ブランチを抽出する。
・抽出されたマージ済みブランチに対してのみ、関連する worktree パスを取得し git worktree remove --force  を実行。その後 git branch -d  でブランチを削除する。
・未マージのブランチは保護対象とし、一切操作しないこと。

Step 2: スケジューラーへの自動化統合
作成したクリーンアップ関数を、既存の定期稼働タスク（tools/mlops_trigger.py など適した定期実行のライフサイクル内）から呼び出すように配線し、人間の手作業なしで自動的に不要リソースがパージされるアーキテクチャを確立すること。
文字列置換（str.replace等）によるコード変更は禁止します。必ずASTベースのツールか安全な編集を用いてください。

Step 3: 静的解析と厳密なコミット
実装完了後、uv run ruff check tools/ を実行し、構文エラーがないことを確認してください（--fixは使用しないこと）。
検証完了後、追加および変更したファイル群を明示的に指定してGitコミットを行ってください。
コミットメッセージ例: "feat(infra): Gitマージステートに基づく一時Worktreeの安全な自動クリーンアップ機構の追加"
※絶対制約: git add . は厳禁です。必ず対象ファイルパスを個別に指定すること。
