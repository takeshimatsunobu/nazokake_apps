【ミッション: 異常検知時の自律ロールバック機構（Fail-Safe）の実装】
Nazo-Agentがコードを修正・マージした後、6次元定量評価ゲート（ベンチマーク）で退行（Fail）が検知された場合に、人手の介入なしにシステムを安全な状態へフォールバックさせる自律ロールバック機構を実装してください。

Step 1: ロールバックロジックの実装
Nazo-Agentの修正を評価するパイプライン（例: tools/mlops_pipeline_agent.py 等）に、評価ゲート不合格時のフォールバック処理を追加すること。
直近のAgentによる修正コミットハッシュを特定し、git revert --no-edit HEAD （または対象ハッシュ）をサブプロセス経由で実行するロジックを構築せよ。

Step 2: 厳格なFail-Closedの徹底（Blast Radiusの最小化）
git revert 実行時にコンフリクトが発生した場合など、自動リバート自体が失敗するエッジケースを必ず想定すること。
その場合は不確実な状態での処理続行（Fail-Open）を絶対に許容せず、直ちに git revert --abort または git reset --hard HEAD を発行して作業ツリーをクリーンな状態に保ったまま、Exit 1 で処理を物理的に遮断（Fail-Closed）せよ。

Step 3: 静的解析とコミット
実装完了後、静的解析（ruff check 等）を実行し、問題がないことを確認してからコミットすること。
※絶対制約: git add . は厳禁です。作業ツリーの汚染を防ぐため、必ず変更対象のファイルパスを個別に指定してコミットを実行すること。
