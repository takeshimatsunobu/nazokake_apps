【ミッション: 非対話的SSH接続における環境変数未解決エラー（docker: command not found）の修正】run_verification_server.ps1 の gcloud compute ssh 経由で実行されるリモートスクリプト内で、docker: command not found (Exit Code 127) が発生しています。これは、非対話的シェルでは ~/.bashrc がロードされず、Rootless Dockerの PATH と DOCKER_HOST が未設定になるためです。tools/deploy/run_verification_server.ps1 の $remoteScript ブロックの冒頭（set -euo pipefailの直後）に、以下の2行を追加して環境変数を明示的に設定してください。export PATH=$HOME/bin:$PATH
export DOCKER_HOST=unix:///run/user/$(id -u)/docker.sock修正後、PowerShellの構文エラーがないことを確認し、変更した run_verification_server.ps1 をコミットしてください。※絶対制約: git add . は厳禁です。変更したファイルのみを明示的にコミットすること。
