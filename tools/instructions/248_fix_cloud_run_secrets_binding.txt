【ミッション: Cloud RunへのGemini APIキー（シークレット）バインド設定の修正】

本番環境で `401 UNAUTHENTICATED (ACCESS_TOKEN_TYPE_UNSUPPORTED)` エラーが発生し続けています。
これは、Cloud Run上のアプリが `GEMINI_API_KEY` を認識できず、デフォルトのADC（サービスアカウント）でGemini APIを叩こうとして失敗している典型的なエラーです。

Step 1: デプロイ設定の調査
`.github/workflows/deploy_cloud_run.yml` などのデプロイ設定ファイルを確認してください。
Cloud Runへのデプロイコマンド（`gcloud run deploy`）において、`GEMINI_API_KEY` をSecret Managerから環境変数としてコンテナに渡す設定（例: `--update-secrets=GEMINI_API_KEY=...` または `--set-secrets`）が欠落していないか調査してください。

Step 2: デプロイ設定の修正
もしシークレットを渡す設定が欠落している場合は、デプロイコマンドに設定を追加してください。
（※シークレット名はプロジェクトの規約に従うか、既存のシークレット設定を参考にしてください。通常は `GEMINI_API_KEY=GEMINI_API_KEY:latest` のような形式になります）

Step 3: 動作確認とコミット
修正が完了したら、変更をコミットし、リモートへPushしてデプロイパイプラインを再起動してください。
完了後、デプロイ設定のどこが欠落していたか、どのように修正したかを報告してください。
