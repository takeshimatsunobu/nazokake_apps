1. `tools/nazo_agent.py` 内に、入力テキストの行数および文字数を計算し、許容範囲内かを判定する `check_cognitive_load(text: str, max_lines: int | None = None, max_chars: int | None = None) -> tuple[bool, str]` 関数を定義してください。
2. 以下の定数を定義し、ハードリミットとして使用してください。

   - `MAX_TOTAL_CONTEXT_CHARS = 40000`
