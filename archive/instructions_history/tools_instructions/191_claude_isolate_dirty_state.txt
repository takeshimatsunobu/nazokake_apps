【ミッション: メインラインの完全浄化（Dirty Stateの隔離）と正規履歴の統合】
外部SRE監査の提言に基づき、メインブランチを「100%クリーンでデプロイ可能な状態」へ復元します。以下の手順を厳密に実行せよ。

Step 1: 独自コンテンツ（100件超の指示書履歴）のメインライン統合
ユーザー承認に基づき、保留していた tools/instructions/tools/ は破棄せず、現在のブランチ（メインライン）に git add し、コミットすること。
コミットメッセージ例: "chore(instructions): 071〜190番の独自コンテンツ(設計ドラフト・レビュー等)を正規履歴として追納"

Step 2: 隔離ブランチの作成とDirty Stateの退避
現在のブランチから新しい検証用ブランチ audit/dirty-state-20260721 を作成してチェックアウトすること。
作業ツリーに残存しているすべての未追跡ファイルおよび変更（SSoT_architecture.md、tools/dataset/agent_sft.jsonl、Nazokake_localLLMサブモジュール、project_context.txt 等の一切の差分）を git add . でステージングし、コミットして隔離すること。
コミットメッセージ例: "chore: 手動精査待ちの未検証差分（Dirty State）を隔離"

Step 3: メインラインの完全浄化（Purify）
元のブランチ（メインライン）へチェックアウトして戻ること。
その後、git reset --hard HEAD および git clean -fd を実行し、Gitの追跡履歴と物理ファイルが完全に一致する「100%クリーンな状態」を強制復元すること。
※ 実行後、git status を実行し、作業ツリーが完全にクリーンであることを証明すること。
