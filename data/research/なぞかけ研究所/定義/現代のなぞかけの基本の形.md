## 🧩 現代のなぞかけの基本の形

現代のなぞかけは、必ずこの３つのステップで言います。

「【A】とかけて、【B】ととく。その心（こころ）は……どちらも【C】でしょう」

これだけです！では、A、B、Cにそれぞれ何が入るのかを説明します。

### A・B・C の正体

* 【A】お題（おだい）： 最初に決めるテーマです。好きな言葉でOKです。
* 【B】ぜんぜん違うもの（解き）： Aとはまったく関係のないものを探します。AとBが離れていればいるほど、聞いた人は「えっ、どういうこと？」と引き込まれます。
* 【C】２つの共通点（こころ）： AとBをむすびつける「共通点」です。ここでダジャレ（同音異義語）を使うのが、なぞかけの最大のポイントです。

## 💡 実際の例で仕組みを見てみよう！

言葉だけだと難しいので、例を出して分解してみますね。

「運動会」とかけて、「写真」ととく。 その心は……どちらも「とる」と嬉しいでしょう！

これを公式に当てはめて、なぜこのなぞかけが成功しているのかを表で見てみましょう。

|  |  |  |  |
| --- | --- | --- | --- |
| 記号 | パーツの役割 | 今回の言葉 | 意味・理由 |
| A | お題 | 運動会 | スタートのテーマ。 |
| B | ぜんぜん違うもの | 写真 | 運動会とは直接関係ないもの。 |
| C | ２つの共通点 | とる | 運動会では「1位を取る」    写真では「笑顔で撮る」 |

このように、「取る」と「撮る」という同じ「とる」という音なのに、AとBで違う意味（違う漢字）になっているのが分かりますか？ これが「うまい！」と言われるなぞかけの基本構造です。

## 🚀 自分で上手ななぞかけを作るコツ

仕組みがわかったところで、自分で作るための裏ワザを１つ紹介します。それは「C（共通点）から先に考える」という方法です。

1. いろんな意味を持つ言葉（C）を探す 「かける（掛ける・書ける）」「あがる（上がる・揚がる）」「ひく（引く・弾く）」のように、違う漢字が当てはまる言葉を考えます。
2. Cから、AとBを連想する 例えば「ひく」を選んだとします。 「風邪を引く」から連想して → 【A：お医者さん】 「ピアノを弾く」から連想して → 【B：音楽室】
3. 公式に当てはめる 「お医者さん」とかけて「音楽室」ととく。その心は、どちらも「ひく（風邪を引く・ピアノを弾く）人が集まるでしょう」。

## ⏳ なぞかけは時代とともに進化する！

実は、なぞかけのルールや使われる言葉は、時代によって変化してきました。

* 昔（江戸時代など）： 昔のなぞかけはただのダジャレではなく、和歌のテクニック（掛詞など）や当時の文化の知識がないと解けない、少し難しいものが多くありました。
* 現代： テレビの演芸番組などの影響もあり、誰もがパッと聞いて分かりやすい「同音異義語（ダジャレ）」を使った今のスタイルが主流になりました。
* そして未来へ： これからも、言葉の変化とともになぞかけも進化し続けます。例えば、「クラウド（空の雲・データの保存場所）」や「アプリ」といった新しい言葉が生まれるたびに、昔の人には絶対に思いつかない新しい【C】（共通点）が発見されています。

なぞかけは、その時代の「言葉」をうつす鏡です。ぜひ、現代に生きる皆さんにしか作れない、新しいなぞかけを発明してみてくださいね！
