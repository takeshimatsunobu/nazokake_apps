🔰 序の巻：基本の遊び方

まずは「⚙️ からくり生成」タブで、好きなお題を入力してみてください。最新のAIが瞬時になぞかけを作ります。

⚔️ 破の巻：デュアルAIの仕組み
▼

当システムは、なぞかけを考案する「生成AI（ボケ役）」と、それを11の評価軸で厳しく採点する「評価AI（審査員役）」の、2つの頭脳（デュアルAI）が連携しています。

💡 しかし、AIにも弱点があります。
論理的な計算は得意でも、人間特有の「笑いのツボ」や「言葉の絶妙なニュアンス」はまだ完璧には理解できていません。

そこで、「📜 道場破り」タブの出番です。あなたがAIの作品に「星評価」を下し、しっくりこない部分を「赤ペン先生」として添削すると、それが『人間が本当に面白いと感じる模範解答』として蓄積されます。

皆様からのフィードバックを「新しい教科書」として再学習させ、AIを真の天才なぞかけ芸人へと進化させる学術的プロジェクトです。

🕸️ 急の巻：11の評価軸（学術的探求）
▼

当システムの分析官AIは、単なる言葉遊びの枠を超え、認知科学や言語学などの学術的背景に基づいた「11の評価軸」で作品を本格採点しています。

【第1の柱：言語と技巧】 職人としての基礎

自然さ / 技巧性 / リズム / 韻律

【第2の柱：論理と共感】 笑いと感情のコア

意外性 / 論理・納得感 / 文化的背景

【第3の柱：芸術性と深み】 芸術的評価の真骨頂

視覚的喚起力 / 感覚的表現 / クロスモーダル / 存在論的深み
